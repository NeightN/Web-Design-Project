# Web-Design-Project – Praktický lékař (ČZU PEF)

Studentský semestrální projekt pro **Českou zemědělskou univerzitu v Praze (ČZU)** – **Provozně ekonomickou fakultu (PEF)**, do předmětu **Web design**.  
Cílem je návrh a implementace vícestránkového webu na téma **praktický lékař / ordinace**, včetně základních interakcí v JavaScriptu.

## Spuštění projektu

Projekt nevyžaduje žádnou instalaci ani build.

1. Otevři složku:
   `Semester prject for WD/Website/`
2. Spusť soubor:
   `index.html` (dvojklikem v prohlížeči)

Doporučeno: prohlížet v moderním prohlížeči (Chrome/Edge/Firefox).

## Použité technologie

- **HTML5**
- **CSS3**
- **JavaScript**
- Ikony: **Font Awesome** (načítáno z CDN)

## Struktura projektu (hlavní část webu)

- `Semester prject for WD/Website/index.html` – úvodní stránka
- `Semester prject for WD/Website/style.css` – styly
- `Semester prject for WD/Website/script.js` – skripty a interaktivita
- `Semester prject for WD/Website/assets/` – obrázky, ikony a další statická média
- `Semester prject for WD/Website/pages/` – podstránky webu:
  - `services/` – služby
  - `doctors/` – lékaři / tým
  - `contacts/` – kontakty
  - `price_list/` – ceník
  - `patient/` – sekce „Pro pacienty“ (praktické informace apod.)
  - `search/` – stránka vyhledávání

## Funkce a obsah (výběr)

- Navigace včetně rozbalovací sekce **„Pro pacienty“**
- Responzivní menu (mobilní „drawer“)
- Sekce úvodní stránky:
  - **O nás**
  - **Naše služby**
  - **Náš tým**
  - **Mapa** (vložená přes Google Maps iframe)
  - **Ordinační hodiny** (tabulky)
- **Registrace**: tlačítko „Registrovat se“ otevírá registrační modální okno s formulářem  
  (včetně výběru data/času a checkboxu souhlasu se zpracováním osobních údajů)
